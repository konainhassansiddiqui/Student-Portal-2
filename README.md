# Student Portal

A simple React + Vite student portal with four cards, local portrait images, view counters, and show/hide contact details.

## Run in VS Code
1. Extract the ZIP file.
2. Open the `student-portal` folder in VS Code.
3. Open Terminal and run `npm install`.
4. Run `npm run dev` and open the localhost link shown in the terminal.

## File structure
- `src/App.jsx`
- `src/App.css`
- `src/main.jsx`
- `src/components/Navbar.jsx`
- `src/components/Welcome.jsx`
- `src/components/StudentCard.jsx`
- `src/assets/` (four local SVG portraits)
